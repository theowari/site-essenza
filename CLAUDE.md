# Project rules

- `backup/index.html` must stay untouched and ignored. Never edit it, and don't use it as a reference while working. Only change `index.html` (project root).
- Exception: if a change to `index.html` causes errors, restore `index.html` from `backup/index.html`, which is the previous version. Restoring only reads the backup; it is never modified.

## Preferences

- Always use [Phosphor Icons](https://phosphoricons.com) for icons. Never use emojis anywhere (UI, copy, comments, docs).
- If not enough images are provided, source them from [Unsplash](https://unsplash.com/pt-br).
